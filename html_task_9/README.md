# 🌍 GT Holidays – Travel & Tourism Website

## 📌 Project Overview

**GT Holidays – Travel & Tourism Website** is a frontend webpage developed using **HTML5 and Tailwind CSS**. The project showcases popular tour packages, travel experiences, company information, and contact details in a travel-themed layout.

The website introduces different travel package categories, highlights the company's travel experience, and displays corporate office information, branch locations, and social media links.

This project was developed to practice HTML structure, Tailwind CSS utility classes, image layouts, typography, spacing, and webpage design.

## 🎨 Tailwind CSS Concepts Used

| Tailwind Class | Purpose                        |
| -------------- | ------------------------------ |
| `h-170`        | Attempts to set element height |
| `w-500`        | Attempts to set element width  |
| `ml-50`        | Applies left margin            |
| `mt-5`         | Applies top margin             |
| `-mt-100`      | Applies negative top margin    |
| `p-10`         | Adds padding                   |
| `text-2xl`     | Sets large text size           |
| `font-serif`   | Applies a serif font           |
| `rounded-xl`   | Rounds element corners         |
| `shadow-2xl`   | Adds a large shadow            |
| `border`       | Adds a border                  |
| `bg-gray-900`  | Applies a dark gray background |
| `text-white`   | Sets text color to white       |

**Note:** Some classes in the original code, such as `h-170`, `w-500`, and `ml-280`, may not be available in Tailwind's default spacing scale. They may need custom configuration or replacement with supported utilities.

## 🖼️ Important Note About Image Paths

The original code uses Windows-specific paths, such as:

```text
C:\Users\ADMIN\Desktop\HT\India-Tour-Packages-770x375.webp
```

These paths work only on the computer where the images are stored. They will not work correctly when the project is uploaded to GitHub or hosted online.

Place the images inside your project directory and use relative paths:

```html
<img
  src="images/India-Tour-Packages-770x375.webp"
  alt="India Tour Packages"
>
```

For social media icons, use paths such as:

```html
<img src="png/instagram (1).png" alt="Instagram">
```

Ensure that the folder names and image filenames match the paths in your HTML.
