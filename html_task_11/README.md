# 🍨 Maharaja Ice Cream Website

## 📌 Project Overview

**Maharaja Ice Cream Website** is a frontend web development project built using HTML5 and Tailwind CSS. It presents an ice cream brand through a colorful webpage featuring a welcome section, company information, catering services, product details, and an image gallery.

The design uses pink, green, and yellow colors, along with image cards and grid layouts, to create an attractive ice cream website.

## ✨ Features

* **Navigation Bar** – Includes Home, About Us, Ice Cream, Gallery, and Contact sections.
* **Hero Banner** – Displays a large ice cream image.
* **App Promotion Section** – Introduces a mobile app download call-to-action.
* **Welcome Section** – Presents the Maharaja Ice Cream brand and introductory content.
* **Catering Services** – Highlights ice cream catering for weddings, corporate events, and birthdays.
* **About Us Section** – Includes company profile and director profile content.
* **Mission Section** – Presents product, economic, and social mission information.
* **Quality Policy** – Displays a quality statement and supporting bullet points.
* **Our Menu** – Features an ice cream product description and a booking button.
* **Ice Cream Gallery** – Displays different ice cream varieties using a grid layout.
* **Tailwind CSS Styling** – Uses utility classes for colors, typography, spacing, rounded corners, and grid positioning.
* **Hover Effects** – Adds interactive color changes to buttons.

## 🛠️ Technologies Used

* **HTML5** – Structures the website content.
* **Tailwind CSS** – Styles the website using utility classes.
* **CSS Grid** – Organizes navigation items, service cards, company information, and gallery images.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Ensure that all required images are available in the correct folders.
4. Open `index.html` in your browser.

You can also install the **Live Server** extension in Visual Studio Code and select **Open with Live Server**.

**Note:** An internet connection is required to load Tailwind CSS from the CDN.

## 🖼️ Image Path Configuration

The current HTML uses local Windows paths, such as:

```html
<img src="C:\Users\ADMIN\Desktop\HT\ice cream\matka-kulfi.jpg">
```

These paths will not work on other computers or after uploading the project to GitHub.

Use relative paths instead:

```html
<img src="images/matka-kulfi.jpg" alt="Matka kulfi">
```

This makes your project easier to share, host, and maintain.
