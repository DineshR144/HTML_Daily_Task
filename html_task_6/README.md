# Chime Banking Website Clone

A responsive banking website UI inspired by **Chime**, created using **HTML and Tailwind CSS**. This project focuses on recreating a modern financial-services webpage layout with promotional sections, member reviews, app download buttons, and a detailed footer.

## Project Overview

This project is a frontend practice project designed to demonstrate how **HTML and Tailwind CSS** can be used to build a modern banking website interface.

The webpage includes promotional banking features, security information, customer reviews, app download sections, mission content, and footer navigation.

## Technologies Used

* Tailwind CSS Browser CDN
* CSS3

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Place all required images inside an `images` folder.
4. Update the image paths in `index.html`.
5. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code to preview the website.

## Important Note About Image Paths

The original project uses local Windows paths such as:

```html id="q6n1ya"
<img src="C:\Users\ADMIN\Desktop\HT\chime_prime.webp">
```

These paths will only work on the original computer.

For GitHub, use relative paths:

```html id="0y8h2w"
<img src="images/chime_prime.webp" alt="Chime Prime">
```

Do the same for all images, including the App Store, Google Play, security, hero, and support images.
