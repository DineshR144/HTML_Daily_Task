# MANI RATNAM – Mani Talkies

A simple HTML-based webpage dedicated to **Mani Ratnam**, one of the prominent filmmakers in Indian cinema. This project demonstrates basic HTML concepts including headings, paragraphs, text formatting, lists, multimedia elements, hyperlinks, and page structure.

## Project Overview

**MANI TALKIES** is a static HTML webpage presenting information about filmmaker **Mani Ratnam**, including his early life, career, notable films, and selected multimedia content.

The project was created as a beginner-level HTML practice project to understand the fundamentals of building a webpage.

## Features

* Mani Ratnam introduction and biography
* Early life section
* Bold, italic, highlighted, and formatted text
* Ordered and unordered lists
* Description list
* Image display
* Audio player
* Video player
* YouTube trailer link
* Center-aligned headings and multimedia content
* Basic HTML page structure

## Technologies Used

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Make sure the image, audio, and video files are available.
4. Open `index.html` in any modern web browser.

## Note

The current project uses local Windows file paths for the image, audio, and video files. For GitHub deployment or sharing the project online, these files should be placed inside the project folder and referenced using **relative paths**.

Example:

```html
<img src="images/images.jpg" alt="Mani Ratnam">

<audio controls>
    <source src="audio/Ok-Kanmani-Love-Bgm.mp3">
</audio>

<video width="640" height="360" controls>
    <source src="video/Ok-Kanmani.mp4">
</video>
```
