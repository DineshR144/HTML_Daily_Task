# Hospital Application Form

A simple **HTML-based Hospital Application Form** designed to demonstrate basic form elements and user input fields. This beginner-level project allows users to enter patient information and select a doctor, appointment date, and appointment time.

## Project Overview

The **Hospital Application Form** is a static HTML webpage created for practicing HTML forms and input elements.

The form collects basic patient details and appointment information through text fields, number input, dropdown selection, date and time inputs, and a submit button.

> **Note:** This is a static HTML practice project. It does not store patient information or create real hospital appointments.

## Features

* Hospital application form
* Field name input
* Patient name input

## Form Fields

### Patient Information

The form collects the following patient details:

* Field Name
* Patient Name
* Age
* Disease

### Doctor Selection

Users can select a doctor from the dropdown list:

* SURIYA
* VIJAY
* AJITH

### Appointment Details

The form provides separate fields for:

* Appointment Date
* Appointment Time

### Confirmation

A submit button is provided to confirm the appointment:

```html
<input type="submit" value="Conform Appoinment">
```

## How to Run

1. Create a file named `index.html`.
2. Copy the provided HTML code into the file.
3. Save the file.
4. Open `index.html` in a web browser.
5. Enter the required information and select an appointment date and time.

No additional software or dependencies are required.
