# THE ONE RESTAURANT 🍽️

## 📌 Project Overview

**THE ONE RESTAURANT** is a basic restaurant website created using **HTML5**. The project presents a restaurant experience in Chennai with an introduction, restaurant interior and exterior images, a weekly food menu schedule, and customer reviews.

This project was developed as an **HTML practice project** to understand webpage structure, text formatting, images, tables, and basic styling.

---

## ✨ Features

* Restaurant introduction
* Chennai dining experience information
* Interior restaurant image section
* Exterior restaurant image section
* Weekly food menu schedule
* Breakfast, lunch, and dinner menu
* Customer reviews
* Customer star ratings
* Black background with white text
* HTML table for menu scheduling
* Basic webpage formatting

## 🧱 HTML Concepts Used

| HTML Element | Purpose                                     |
| ------------ | ------------------------------------------- |
| `<html>`     | Defines the HTML document                   |
| `<head>`     | Contains document information               |
| `<title>`    | Defines the webpage title                   |
| `<body>`     | Contains webpage content                    |
| `<h1>`       | Main heading                                |
| `<h2>`       | Section headings                            |
| `<p>`        | Paragraph content                           |
| `<center>`   | Centers content                             |
| `<hr>`       | Creates horizontal lines                    |
| `<image>`    | Used to display images in the provided code |
| `<table>`    | Creates the food menu                       |
| `<tr>`       | Creates table rows                          |
| `<th>`       | Creates table headings                      |
| `<td>`       | Creates table data                          |
| `<b>`        | Makes text bold                             |
| `<br>`       | Creates a line break                        |

## 🖼️ Image Path

The current code uses Windows local image paths such as:

```text
C:\Users\ADMIN\Desktop\HT\Restaurant-Interior.jpg
```

These paths work only on the computer where the images are stored.

For GitHub, place your images inside the project folder:

```text
images/
```

Then use relative paths such as:

```html
<img src="images/Restaurant-Interior.jpg" width="460" height="360">
```

This makes the project portable and allows the images to work on other computers.
