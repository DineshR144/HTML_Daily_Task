# Contemporary Love Poems

A simple and visually styled webpage showcasing a collection of **Contemporary Love Poems** using **HTML5 and Tailwind CSS**.

## Project Overview

This project presents the titles and selected opening lines of contemporary love poems in different colors and styles. A gradient background and Tailwind CSS utility classes are used to create a simple colorful design.

## Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS CDN

## Features

* Contemporary love poem collection
* Colorful poem headings
* Gradient background
* Tailwind CSS utility classes
* Center-aligned heading and image
* Responsive styling with Tailwind CSS
* Simple and beginner-friendly HTML structure

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Make sure the poem image is inside the `images` folder.
4. Open `index.html` in a web browser.
5. The webpage will load the poem collection with Tailwind CSS styling.

## Important Note

The original HTML uses a local Windows file path for the image:

```html
<img src="C:\Users\ADMIN\Desktop\HT\poem images (2).jpg">
```

For GitHub, use a relative path instead:

```html
<img src="images/poem-image.jpg" height="350" width="500">
```

This allows the image to work correctly when the project is uploaded to GitHub.
