# Credit Card Payment Form

A simple **Credit Card Payment Form** created using **HTML and CSS**. This project demonstrates form elements, radio buttons, input fields, dropdown selection, and different CSS border styles.

## Project Overview

This project provides a basic payment form where users can:

* Select a card type
* Enter a credit card number
* Re-enter the credit card number
* Enter an email address
* Enter a mobile number
* Enter a payment amount
* Select a bank account
* Submit the payment form

## Technologies Used

* HTML5
* CSS3

## Features

* Card type selection using radio buttons
* Credit card number input fields
* Email input field
* Mobile number input field
* Payment amount input
* Bank account dropdown
* Submit button
* Custom CSS borders
* Rounded input borders
* Basic form layout

## CSS Border Styles Used

The project demonstrates different CSS border styles:

* Solid
* Outset
* Dashed
* Groove
* Ridge
* Inset

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Make sure the required card images are available inside the project folder.
4. Open `index.html` in any web browser.
5. Fill in the form and click **Submit**.

## Important Note

The current HTML code uses local Windows file paths for the card images. For GitHub, it is better to place the images inside an `images` folder and use relative paths such as:

```html
<img src="images/visa.png" width="50" height="35">
```

instead of:

```html
<img src="C:\Users\ADMIN\Desktop\HT\Visadebitcardpng-1599584312349.png">
```
